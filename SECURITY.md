# Security Policy

## Supported Versions

Only the latest release of ApkStart is actively supported with security updates.

| Version | Supported |
|---|---|
| 0.6.x (latest) | :white_check_mark: |
| < 0.6.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in ApkStart (for example, command injection, path traversal in APK/ZIP/AXML parsing, privilege escalation, or unsafe IPC exposure):

1. **Do not** open a public GitHub issue for unpatched security vulnerabilities.
2. Report it privately via [GitHub Security Advisories](https://github.com/kaixhdev/ApkStart/security/advisories/new) on the `kaixhdev/ApkStart` repository.
3. Include steps to reproduce, affected version/edition (Store, Installer, or Portable), and any relevant logs.

We will acknowledge receipt and work on a fix as quickly as possible.
